Button — 絨面纖維

不是弦,是布:一層緊密的短纖維(絨毛),靜止時幾乎看不見、只是安靜的質地。 手指滑過去,纖維順著移動方向倒伏,倒伏的地方泛起一道光澤,像絨布被摸過的痕跡, 然後慢慢立回來、光澤消退。摸得越快,痕跡越亮。

hover — 三個 variant

纖維在靜止時透明度只有 10–14%,是質地不是圖案;光澤靠 hover 才浮現。

press 方案 A — 壓痕(這排按按看)

按下 = 拇指壓進布裡:按點周圍的絨毛被壓平、壓暗(一塊指印); 放開 = 絨毛立回來,壓痕在半秒內消失。像壓了一下沙發布面。

press 方案 B — 熨平 → 光澤暈開(這排按按看)

按下 = 整塊布被熨平:所有倒伏歸零、光澤收掉,布面繃出一種安靜的張力; 放開 = 一圈柔和的光澤從按點暈開、邊走邊淡,像放開手之後布面回彈時掃過的光。 始終是亮度在動,纖維本身幾乎不動 — 緊緻的布只會這樣回應。
